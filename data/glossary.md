# Glossary

Official terms stay in English. Page numbers are printed pages.

| Term | Meaning | Where |
|---|---|---|
| Die code | `ND+P`: N dice plus P pips. Attributes, skills, damage and difficulties use it. | core-mechanics#die-codes |
| Pip | The flat `+P` added to a die code. | core-mechanics#die-codes |
| Attribute | One of Dexterity, Knowledge, Mechanical, Perception, Strength, Technical. | p.8 |
| Skill | Ability under an attribute; starts at the attribute's code. | p.8-9 |
| Difficulty number | Target a roll must equal or beat. | core-mechanics#difficulty |
| Opposed roll | Both sides roll; higher wins, initiator wins ties. | core-mechanics#rolling |
| Wild die | One die per roll that explodes on 6 and can cause trouble on a first-roll 1. | core-mechanics#wild-die |
| Complication | Something related to the roll goes wrong; chosen by the gamemaster. | core-mechanics#wild-die |
| Scene / Round | Free-form time / 5-second structured time. | core-mechanics#scenes-rounds |
| Free action | Needs no roll or real effort; costs no multiple-action penalty. | core-mechanics#free-actions |
| Non-roll action | Counts as an action but needs no roll. | core-mechanics#free-actions |
| Reaction skill | Acrobatics, dodge, melee parry, brawling parry (and lightsaber parry). | core-mechanics#reactions |
| Combined action | Characters pooling effort for a bonus led by a command roll. | core-mechanics#combined-actions |
| Preparing / Rushing | +1D per time doubling (max +3D) / half time for half dice. | core-mechanics#time |
| Character Points | Spend for extra exploding dice; also buy permanent improvement. | core-mechanics#character-points |
| Force Points | Double all character dice for a round; returned by heroic use. | core-mechanics#force-points |
| Dark Side Points | Gained by evil acts or calling on the dark side; fall at the roll described. | core-mechanics#dark-side |
